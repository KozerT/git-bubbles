Step 2: Changes

Adding Changes in Git

Imagine building something with LEGO blocks. You add new pieces, change a few things, and sometimes make mistakes.

Wouldn't it be nice to remember how your creation looked before? That's what Git helps us do!

Git keeps track of changes in our files and lets us save different versions of our project.

Think of each commit as taking a picture of your LEGO creation before making more changes. If something goes wrong, we can look back at an earlier version.

1. How to check our changes

Git status helps you see which files have changed.

This shows which files are new, modified or ready to be saved. 

git status
# Example output:
Untracked files:
  drawing.svg

2. How to add our changes

After checking our changes, we need to choose which files we want Git to include in our next snapshot.

This is called staging. Think of it like choosing which LEGO pieces you want to include in a photograph. 

# Add all changes
git add .

# Or add one specific file
git add index.html

3. How to save our changes

Once we have staged our changes, we can save them by creating a commit.

Think of a commit as taking a photograph of your LEGO creation. Each commit records a snapshot of your project, along with a message explaining what changed. 

# Save your staged changes with a message
git commit -m "Update homepage"

4. Other useful Git commands

Git has a few more helpful commands that make it easier to understand, share, and manage our changes.

git diff — Shows the changes in your files that have not been staged yet.

git diff --staged — Shows the changes you have already staged for your next commit.

git push — Sends your local commits to a remote repository, such as GitHub.

git pull — Gets changes from a remote repository and integrates them into your current branch.

git log — Shows the history of commits in your project.

git restore --staged index.html — Removes index.html from the staging area without deleting your changes in the file.

Nursery Tip:

Remember: git add prepares your changes, git commit saves them locally, and git push sends your commits to GitHub.
